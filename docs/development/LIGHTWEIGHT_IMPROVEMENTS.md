# Lightweight Evolution: UwU-CLI Improvement Roadmap

## 🎯 Philosophy: "Impact Over Overhead"
## 💎 Feature Integrity: "No Feature Left Behind"
**IMPORTANT:** This roadmap does NOT remove any existing features. Core differentiators like **Telegram Remote Control**, **Multi-Shell Routing**, and **Cursor IDE Integration** remain first-class citizens. We are simply making them faster and more robust.

To keep UwU-CLI fast and responsive while competing with heavy-weight tools (Aider, Warp), we focus on native Python capabilities and targeted, lightweight libraries.

## 🚀 1. Visual Diffs (Native & Zero-Dependency)
**Issue:** AI changes are currently "black box" until applied.
**Solution:** Use Python's built-in `difflib` combined with `colorama` to show exactly what the AI plans to change before it touches the disk.
*   **Weight:** +0 KB (Native).
*   **Impact:** Massive trust and safety improvement.

## 🧠 2. Smart Context Prefacing (Non-RAG)
**Issue:** Full RAG (Vector DBs) adds significant memory and disk weight.
**Solution:** Implement "Project Awareness" by automatically scanning the root directory for `README.md`, `package.json`, `setup.py`, and current folder structure (`tree` view). This context is injected into every prompt without needing a database.
*   **Weight:** +Minimal (JSON parsing).
*   **Impact:** AI becomes context-aware of the *whole project* immediately.

## 🛡️ 3. "Dry Run" AI Previews
**Issue:** Running AI commands can be destructive.
**Solution:** Every `ai:cmd` or `/f` (fix) command first returns a "Shadow Execution" report:
1.  **Commands to be run.**
2.  **Files to be modified.**
3.  **Potential risks.**
User confirms with a single `y/n` before application.
*   **Weight:** Logic-only.
*   **Impact:** Professional-grade safety.

## ⚡ 4. Command Shadowing & Aliasing
**Issue:** Users forget complex flags.
**Solution:** Lightweight command shadowing. When a user types a command, UwU-CLI non-intrusively suggests the AI-optimized version in a dim color (using `prompt_toolkit` if available, or a simple buffer check).
*   **Weight:** Moderate if using `prompt_toolkit`.
*   **Impact:** oh-my-zsh level feel.

## 🎨 5. Toggleable "Chaotic FX" (The Fun Stuff)
**Issue:** The "UwU" energy shouldn't slow down the "Lord" level engineering.
**Solution:** Move ASCII art and TTS to a background thread and make them strictly toggleable (`config set fx_enabled false`).
*   **Weight:** Code exists, but execution is deferred.
*   **Impact:** Keeps the soul of the project without affecting the core CLI speed.

## 🛠️ Technical Implementation Specs

### Diff Engine (`utils/diff_engine.py`)
```python
import difflib
from colorama import Fore, Style

def show_preview(old_content, new_content):
    diff = difflib.unified_diff(
        old_content.splitlines(),
        new_content.splitlines(),
        lineterm=''
    )
    for line in diff:
        if line.startswith('+'): print(Fore.GREEN + line + Style.RESET_ALL)
        elif line.startswith('-'): print(Fore.RED + line + Style.RESET_ALL)
        else: print(line)
```

## 🎭 6. Toggleable "Chaotic FX" System Design
**Concept:** Maintain the "UwU" identity without forcing it on every session or slowing down the UI.

### Logic Flow
1.  **Registry:** All "Fun" functions (ASCII, TTS, Clapbacks) register with an `FXManager`.
2.  **Global Switch:** A single config key `fx_mode` controls execution:
    *   `hard`: Full UwU (Clapbacks, TTS, Rainbow prompts).
    *   `soft`: Selective (Prompts only).
    *   `stealth`: Zero overhead (Standard dev shell).
3.  **Threaded Execution:** Any ASCII or TTS call MUST be non-blocking.

```python
class FXManager:
    def __init__(self, mode="soft"):
        self.mode = mode

    def run_fx(self, fx_type, func, *args):
        if self.mode == "stealth": return
        if self.mode == "soft" and fx_type == "tts": return

        # Execute fun stuff in background
        threading.Thread(target=func, args=args, daemon=True).start()
```
